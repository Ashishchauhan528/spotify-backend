# Spotify Backend Clone
A Spotify-inspired backend application built using Node.js, Express.js, and MongoDB.
This project implements authentication, authorization, album management, music APIs, and artist/user role handling similar to a real-world music streaming backend system.

# Features
- User Registration & Login APIs
- JWT Authentication
- Role-Based Authorization (User / Artist)
- Protected Routes Middleware
- Create & List Album APIs
- Get All Songs API
- Artist APIs
- User APIs
- MongoDB Database Integration
- Image/File Upload Integration
- Environment Variable Security using dotenv
- Modular MVC Backend Structure

## Tech Stack
